With the [provider mounted](/docs/getting-started/provider), this is
all you need to render a working transfer + bridge widget:

```tsx title="app/send/page.tsx"
"use client";

import { WhiskSend } from "@usewhisk/react";

export default function SendPage() {
  return (
    <main className="mx-auto max-w-md py-16">
      <WhiskSend />
    </main>
  );
}
```

Open the page and you'll see a "Connect wallet" card. Connect a
wallet and the widget walks through the rest:

<Steps>
  <Step>
    Pick source + destination chain, paste a recipient, type an amount.
  </Step>
  <Step>
    Whisk resolves the recipient (raw address, ENS name, or non-EVM address)
    against the destination chain.
  </Step>
  <Step>
    It builds a quote (same-chain transfer or CCTP V2 bridge) and shows the fee
    breakdown.
  </Step>
  <Step>
    The user confirms. Whisk submits the transaction and renders a step rail —
    `authorize → burn → attest → mint` for bridges.
  </Step>
  <Step>
    On success, you get a result card with the final tx hash and an explorer
    link.
  </Step>
</Steps>

## Listening to the flow

Two callbacks cover most analytics needs. Both fire once per attempt
and pass the full `SendSuccess` / `SendFailure` result:

```tsx
<WhiskSend
  onSuccess={({ finalTxHash, steps }) => {
    analytics.track("whisk.send.success", {
      tx: finalTxHash,
      stepCount: steps.length,
    });
  }}
  onFailure={({ error, steps }) => {
    const failedStep = steps.find((s) => s.state === "error");
    analytics.track("whisk.send.error", {
      code: error.name,
      failedOn: failedStep?.name,
    });
  }}
/>
```

For step-by-step observability during a send (e.g., a custom
progress rail), reach for the [`useWhisk`](/docs/hooks/use-whisk)
hook, which exposes the full step list plus every state transition.

## Restricting tabs

`<WhiskSend>` renders two tabs by default: **Send** (same-chain
transfer) and **Bridge** (cross-chain via CCTP V2). Restrict to one
tab when the surface should be single-purpose:

```tsx
{
  /* Bridge-only widget for a cross-chain landing page. */
}
<WhiskSend tabs={["bridge"]} />;

{
  /* Send-only for a same-chain checkout. */
}
<WhiskSend tabs={["send"]} />;
```

## Where this falls short

`<WhiskSend>` is opinionated about layout; it's a card, it's
centred, it owns its width. If you need a different shape (sidebar
wizard, full-page checkout, sheet from the bottom), drop down to
the primitives. See [Components →
Primitives](/docs/components/primitives).
