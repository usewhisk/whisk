---
title: WhiskSend
description: The styled send + bridge widget. The fastest way to ship a USDC payment surface.
---

`<WhiskSend>` is the default Whisk surface. It walks the user
through connect → input → review → send → success, with two tabs:
**Send** for same-chain transfers and **Bridge** for cross-chain
CCTP V2 bridges.

```tsx
import { WhiskSend } from "@usewhisk/react";
```

## Minimum usage

```tsx
<WhiskSend />
```

No required props. Everything is sourced from the surrounding
`<WhiskProvider>`. Past this point, the rest of the props are
opt-in.

## Lifecycle callbacks

| Prop        | Type                            |
| ----------- | ------------------------------- |
| `onSuccess` | `(result: SendSuccess) => void` |
| `onFailure` | `(result: SendFailure) => void` |

`onSuccess` fires when a transfer settles cleanly. `onFailure` fires
when the engine returns a failure result — the `steps` array on the
payload tells you which step tripped it.

## Controlled inputs (locked)

| Prop               | Type     | Effect                      |
| ------------------ | -------- | --------------------------- |
| `amount`           | `string` | Lock the amount field.      |
| `recipient`        | `string` | Lock the recipient field.   |
| `sourceChain`      | `Chain`  | Lock the source chain.      |
| `destinationChain` | `Chain`  | Lock the destination chain. |

## Default inputs (seeded but editable)

| Prop                      | Type     |
| ------------------------- | -------- |
| `defaultAmount`           | `string` |
| `defaultRecipient`        | `string` |
| `defaultSourceChain`      | `Chain`  |
| `defaultDestinationChain` | `Chain`  |

## Tabs

| Prop   | Type                                | Default              |
| ------ | ----------------------------------- | -------------------- |
| `tabs` | `ReadonlyArray<"send" \| "bridge">` | `["send", "bridge"]` |

Pass a single-element array to hide the other tab entirely (e.g.,
bridge-only or send-only surfaces).

## Layout

| Prop          | Type        | Notes                                               |
| ------------- | ----------- | --------------------------------------------------- |
| `title`       | `string`    | Override the card title. Defaults to `"Send USDC"`. |
| `description` | `ReactNode` | Optional copy shown under the title.                |

## A checkout

```tsx
<WhiskSend
  amount="49.99"
  recipient="0xMerchantTreasury…"
  destinationChain="Base_Sepolia"
  tabs={["bridge"]}
  onSuccess={({ finalTxHash }) => {
    router.push(`/order/confirmed?tx=${finalTxHash}`);
  }}
/>
```

## A donate button

```tsx
<WhiskSend
  recipient="0xDAOTreasury…"
  defaultAmount="10"
  onSuccess={() => analytics.track("donation.complete")}
/>
```
